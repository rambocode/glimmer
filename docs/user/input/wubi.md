微明可以换成五笔输入。五笔与拼音是同一个输入法的两种输入方案，中 / 英切换、选词、翻页、标点、译词与 emoji 均与拼音相同；只有组句中的编码规则不同。

## 三个版本

微明随包带三份五笔码表：**86 五笔**、**98 五笔**、**新世纪五笔**。三者只是字根与码表不同，本页所述的按键与行为完全一致，按自己学的那一版选。

三个版本的学习数据各自独立：某个版本下造出的词、在某段编码下选过的字词只在该版本内生效，换到另一个版本后重新记，换回来时原有的记录仍在。
按词语记录的词频、词与词的接续、译词与生词三个版本共用。

## 开启

- **macOS**：「偏好设置 → 通用」的「五笔」弹出菜单，四项为「关」「86 五笔」「98 五笔」「新世纪五笔」；选「关」回到拼音。
- **Windows**：「设置 → 通用」中同名的「五笔」项，四项相同。
- **Linux**：暂无设置界面，需直接修改配置文件。

也可直接修改配置文件（见 [偏好设置](../settings/preferences.md#直接修改配置文件)）。开启五笔后，「通用」页的双拼方案与大千注音设置被忽略，关闭五笔后恢复。
开着时 macOS 菜单栏与 Windows 悬浮状态条显示当前版本，例如「中 · 98 五笔」；macOS 输入法菜单顶部另列出「输入方案：98 五笔」。

## 编码与上屏

- 编码键是 `a` 至 `y` 二十五个字母，一个字或词最多四码。候选按当前输入的编码列出：编码与输入完全相同的字词在前，以输入为开头的较长编码在后（逐键提示）。
- **四码自动上屏**：输入满四码且有完全相同编码的字词时，首选自动上屏，不必按 `Space`。可在「通用」页关闭「四码自动上屏」，关闭后满四码仍停留在候选窗口，按 `Space` 或数字上屏。
- **顶字上屏**：候选窗口中已有候选时，再输入一个字母使得没有任何候选（包括逐键提示），则前一段的首选自动上屏，新输入的字母作为下一个字的第一码保留。
- **空码**：输入四码后没有任何候选时，编码保留在输入行，可按 `Backspace` 逐个删除修改；此时再输入字母，旧编码整段清除、从新字母重新开始；按 `Space` 或 `Enter` 则把编码字母原样上屏。

例（86 五笔）：`gggg` 出 王 并自动上屏；`gg` 出 五 与其他以 `gg` 开头的字；`a` 出 工，`aaaa` 同样出 工。
一级简码的二十五个字三个版本相同，具体编码按所选版本的码表。

## 简码的位置固定

不超过两码的候选（一级、二级简码）只按码表的固定顺序排列，不随使用习惯调整：简码的位置是五笔用户的肌肉记忆，调整后反而会打错。
三码与四码的候选仍按使用习惯排序，同一编码下选过的字词会排到前面。

## 逐键提示与编码提示

- **逐键提示**：输入一两码时，编码以此开头的字词一并列出，短码在前。
- **编码提示**：逐键提示的候选右侧显示其完整编码，可从中看到自己没打完的码。编码与输入完全相同的候选不显示编码。「通用」页可关闭「显示编码提示」（Windows 设置程序中同名）。

## 拼音反查

不知道一个字的五笔编码时，先输入 `z`，再输入该字的全拼：`zzhong` 出 中 与同音字，每个候选右侧标注其五笔编码；`zzhongguo` 出 中国，右侧为该词的编码。
选中后该字上屏，输入行清空。反查只支持全拼，不支持双拼；只输入一个 `z` 时没有候选。

## 自动造词

连续打出的两个字词会被记住：先后打出 中 和 国（中间没有标点、没有切换应用）两次以后，86 五笔下 `khlg` 直接出 中国，输入 `kh` 时也会在逐键提示中出现并标注编码。
新词的编码按五笔的通行规则生成：二字词取每个字的前两码，三字词取前两字的第一码加第三字的前两码，四字及以上取前三字与末字的第一码。
这套规则三个版本相同，各版本按各自码表中的单字编码生成。某个字的编码不足所需位数时不造词。造出的词记在本机，见 [数据与日志](../help/data-and-logs.md)。

## 五笔下的差异

以下拼音功能在五笔下不可用：

- 双拼、大千注音（设置被忽略）。
- 整句输入、拼写纠错、模糊音。
- `v` 算式与中文数字、`u` 码点输入、`rq` / `sj` / `xq` 日期时间：这些字母在五笔下都是编码。`?` 开头的问字照常（问题用拼音输入）。
- 中英混输的英文候选。输入 `-` `,` `.` 等半角标点仍进入英文直输段，按 `Space` / `Enter` 原样上屏。
- 云联想的整句补全。

照常可用：候选旁的译词与生词、emoji、`?` 问字、翻译选中文字、自定义短语、用户词频学习（三码以上）。

按键的差异见 [按键与快捷键](../getting-started/keys.md#输入五笔时)。

## 数据来源

三份码表均来自公开的开源项目，字根与编码规则由王永民发明；各自的许可证全文与署名随安装包附带，「关于」页可查看。

- **86 五笔**：rime-wubi（极点五笔血统），LGPL-3.0；86 版的字根与编码规则已进入公有领域。
- **98 五笔**：98wubi（yanhuacuo）的含词码表，LGPL-3.0。
- **新世纪五笔**：wubixinshiji（GuoBinyong），署名文件声明 LGPL，整理自王永民《五笔字型大一统》的新世纪整合词库。
