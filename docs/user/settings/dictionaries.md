## 随包词库

基础词库 9.4 万条，另有 12 本领域词库随包：法律、医学、地名、成语、诗词名句、IT、财经、饮食、动物、汽车、历史人物、AI 与软件开发。
缺省只开启成语，其余在「偏好设置 → 词库」勾选。领域词库扩充可选词条，并复用已有候选排序和整句转换。

## AI 与软件开发

在「偏好设置 → 词库」勾选「AI 与软件开发」。它覆盖 AI、向量检索、项目协作、日常开发、Git、框架、包管理器、测试部署、工具和配置文件名称，默认关闭。原先开启「AI 与人工智能」的设置继续有效。

中文按拼音输入，例如 `jiansuozengqiangshengcheng` →「检索增强生成」、`weitiao` →「微调」，也支持简拼与双拼。
`aimoxing` 可输入「AI模型」。英文模式下输入 `claude`、`gemini`、`qwen` 等前缀，再选择带完整名称的候选；中文模式也沿用原有中英混输规则。
也可以在配置文件的 `[dictionaries] domains` 列表中加入 `"ai"`，保留其他已启用词库。

型号中的大小写、空格、数字与连接符由候选补全，例如选择「Claude Opus 5」时无需逐个敲出型号字符。前缀匹配忽略名称中的空格、连接符和小数点。

常用开发名称也可直接补全：

| 输入 | 候选 |
|---|---|
| `claudec` | Claude Code |
| `springb` | Spring Boot |
| `cpp` / `cplusplus` | C++ |
| `csharp` | C# |
| `packagej` | package.json |
| `agentsmd` | AGENTS.md |
| `gitfenzhi` | Git分支 |
| `apijiekou` | API接口 |
| `gowork` / `goworkenv` | go.work / GOWORK |

英文模式下，精确匹配仍优先；补全先尊重你的选择习惯，再优先这本开发词库。建议用小写输入码，以保留文件名标准写法；大写输入仍遵循原有英文大小写规则。
`Git分支` 等新混合词按表中的完整输入码输入，不自动改成双拼码；纯中文术语和原有「AI模型」照常支持双拼。

关闭后该词库提供的中文词和英文候选撤销；主词库、其他开启的词库或个人已学会的词仍可能显示。名称清单随版本更新，不保证覆盖全部最新型号。
词库离线使用，不会在输入时联网查询或下载模型。没有显示这本词库时，需要安装包含它的新版输入法。

## 导入用户词库

「偏好设置 → 词库 → 导入词库…」，接受三种格式：

- 微明 TSV：每行 `词<Tab>拼音<Tab>词频`，拼音音节间以空格分隔。
- Rime 的 `.dict.yaml`：读取名称和文件内的词条，词条须为 `词<Tab>拼音[<Tab>权重]`，拼音音节间以空格分隔，非整数权重按 1 处理。不支持 `import_tables` 引用的其他词库、自定义 `columns` 列顺序或 `.schema.yaml` 方案配置。
- 微明 `.qj`：他人制作的词库文件，自带名称与许可证。

TSV 与 Rime 词库导入时，`lue` / `nue` 自动统一为 `lve` / `nve`。词库用 `v` 表示 ü。
旧词库里写成 `lue` / `nue` 的词也照常能打。

导入后列在随包词库之下，显示名称、条数、许可证。可单独开关；「移除」只将文件移到一旁，不删除。

Windows 导入时会转换成 `.qj` 并自动启用，设置页显示导入条数或失败原因。没有可用词条的文件不能导入。
文件选择窗口支持按 Ctrl 或 Shift 多选，批量导入 YAML、TSV 或 `.qj`；单个文件失败不影响其余文件，完成后显示成功、失败数量及各文件结果。
输入法运行时通常在约一秒内自动加载；同名重新导入和移除也会自动更新，无需重启。
若手动编辑配置时出现格式错误，词库仍按上次有效的开关设置加载；修正配置后自动恢复应用新设置。
Rime 文件要经「导入词库…」转换，直接放进词库目录不会加载。

## 项目词库

具体项目里的模块名、服务名和业务术语，可以整理成独立 TSV，在「导入词库…」中导入并按项目手动开关。
只整理确认有用的专名，文件保持本地；输入法不会扫描仓库、上传它们或自动加入公共词库。

三列分别为词、输入码、初始权重，中间使用真正的 Tab。例子：

```tsv
订单聚合	ding dan ju he	30
计费服务	ji fei fu wu	30
BillingService	@billingservice	40
订单API	@dingdanapi	30
```

中文写空格分隔的拼音；英文或混合名称的输入码以 `@` 标记，后面写小写英文字母和数字，实际输入时不敲 `@`。
同一个词可写多个输入码；避免让不同词共用输入码。多本导入词库存在同码冲突时，先加载的词条保留。
长指令和完整命令适合放个人快捷短语，词库主要用于名称、术语和固定搭配。
