# 补充常用词：词库缺的常用词怎么找、怎么补（2026-09-17）

上游 issue #98 / #121 / #127 报的都是「常用词没有」：`qucan` 出 午餐、`tanchu` 出 演出、`bofangqi` 出整句 播放其、一十 翻页也找不到。
查下来 取餐 / 弹出 / 弹窗 / 这时 / 一十 / 播放器 在主词库与语言模型里都没有。

## 为什么漏

主词库是「规范字 + 现代汉语常用词表 + THUOCL + 语料挖词 + 短语层」。常用词表是词典词头，收不全；另外两条挖词的路各有盲区：

- `mine` 只看分词后落成连续单字的段，还要相邻字对 PMI ≥ 3。播放器 = 播放 + 器，不是单字段；这时 = 这 + 时、弹出 = 弹 + 出，成分是高频虚字，PMI 过不了线。
- `phrases` 要总次数与对话语料次数都 ≥ 2000，取餐（语料 27 次）、弹窗（78 次）差得远。

所以缺的是一类「一个成分是高频虚字或已成词」的词，语料次数从几十到几万都有。

## 找法

语料不在本机时也能做：发布的 `lm.qj` 里有全部一元与二元计数，缺的词在语料里被切成成分词，成分二元 c(a,b) 就是它的次数
（与 `bigram --phrases` 合成计数同一公式，三字以上按链式估）。

1. 白名单：许可清楚的外部词表，只取词头：CC-CEDICT（MDBG 2026-09-15 版，CC BY-SA 4.0，10.5 万条，带读音）与 jieba `dict.txt`（MIT，34.9 万条，无读音）。
   雾凇拼音与五笔码表不当词源。
2. `dict-convert gaps`：白名单里 2–4 个汉字、主词库与 `dicts/` 领域词库都没有、语言模型也不是 token 的词，按成分二元合成次数；
   读音 CEDICT 给了就用，否则由成分词的主读音拼。37.7 万个候选里合成次数 ≥ 20 的 6.2 万条。
3. 预筛：CEDICT 词 ≥ 200 次、jieba 独有词 ≥ 1000 次（jieba 杂词多，门槛高），再用短语层的边界规则去掉 338 条（的 / 了 开头、不 / 很 / 数词结尾、叠字），剩 3,890 条。
4. 人工审：分五块逐条过。留日常打字会整块打的真词与固定说法；丢句法碎片（一名 / 并不）、叠字拟声、人名 / 小地名 / 作品名、维基百科腔组合（每平方 / 隶属于）、
   生僻古旧、港台用词、低俗词。留 1,241 条（约 32%），多音字逐个核过（长按 chang、重来 chong、倒时差 dao；流鼻血 改 xue）。
5. 人工清单：手机电脑界面与生活服务词，白名单或门槛漏掉的（弹窗 / 长按 / 下拉 / 登录框 / 快递柜 / 息屏 / 取件 / 小程序 …）136 条，次数同样合成，不到 20 按 20。

合并去重共 1,357 条，放 `assets/lexicon/common_words.tsv`（`词\t次数\t拼音`，与 `domain_words.tsv` 同格式）。

## 进词库与语言模型

与领域词一样：词库走 `lexicon --extra-words`，语言模型走 `bigram --phrases` 的合成路（理由见 `domain-words.md`：低频词当 token 统计会吸走成分的二元证据，伤整句）。
合成后整句里它们的得分与原来的成分路径一样，词级多一个能整块选的词。

没有语料时用 `dict-convert supplement`：读 `assets/lexicon/dict.tsv` 与已有 `lm.qj`，补充词按 (词, 音节) 二分插进词库（原有行顺序不动）、
在 `lm.qj` 的计数上合成一元与前后接二元，写回 `dict.tsv` 与 `lm-*.tsv` 再打包。在原始 `lm.qj` 上跑与在补过的 `lm.qj` 上再跑，排序后的 TSV 逐行相同。
语言模型多 1,355 个词、9.9 万条合成二元（2 条合成次数 < 3 没进，如 登录框，只在词库里）；词库 92,825 → 94,182 条。
AI 领域词库按新主词库重新排除后少 3 条（最大化 / 概率论 / 路由器）。

| 输入 | 之前 | 之后 |

| bofangqi | 播放其（整句）/ 播放 / ⏯ | **播放器** / 播放 / ⏯ |
| zheshi | 这是 / 这事 / 赭石 | 这是 / 这事 / **这时** |
| tanchuang | 探闯（整句）/ 贪吃 / 探测 | **弹窗** / 弹出 / ⏏ |
| yishi | 一时 / 意识 / 仪式（没有 一十） | 同左，**一十 第 15** |

一十 语料只有 144 次，一时 / 意识 / 仪式 / 一世 / 医师 都是几千；按规矩不给它编次数，能在候选里找到、选一次个人学习就顶上去。

回归：词库里词频最高、拼音互不相同的 3,000 个 2–4 字词逐个冷查，首选**一条没变**；前三变了 89 条，都是第 2、3 位多出补充词的补全
（renkou 多 人口密度、tongxue 多 同学们、kuaidian 里 快点儿 排到 快递 前面）。nihao / women / daima / shijian / celue 前三不变。

本机没有整句评测集与输入日志，两把尺子（`--eval-text` / `--replay`）这次没跑；合成计数不改变已有词的整句得分，风险在词级排序，由上面的回归兜底。
