## 同输入串选择加分（2026-09-22）

词级排序原来第 5 级是「同一输入串、同一位置下用户选过几次」，**硬**压在第 6 级的上下文得分之上：选过一次就锁死首选。
这次把它拆成得分里的一份加分 `ranking::choice_bonus(n) = 系数 × ln(1 + min(n, 封顶))`，系数与封顶挂在 `Interpolation` 上
（`--tune choice=` / `choice-cap=`），在冻结日志上扫了一遍。**结论：系数 1.5、封顶 20。**

### 尺子

- 冻结日志 `/tmp/glimmer-eval/input-log-2026-09-22.jsonl`，可评词级上屏 9575 条；`glimmer-cli --replay <日志> --misses 0`，
  内存学习从零起，云联想关，不带神经重排。配置用的是用户数据副本，所以下面的绝对值只在本轮内部可比。

### 「收到」后面的 `youjian` 为什么还是 右键

这次改动的起因是：用户的 `youjian` 选过 右键 3 次、邮件 0 次，「收到」后面仍出 右键。**改完之后还是 右键**，
但原因不是选择记录：把个人 n-gram 关掉（`--tune cap=0`）再看，硬规则仍出 右键，软加分出 邮件——选择那一关已经过了。
挡在前面的是个人 n-gram 自己：`user-ngram.tsv` 里有 `收到 右键 2` 和 `<s> 右键 2`（用户以前接受过错词，模型把错词学进去了），
而 `收到 邮件` 一次都没有。插值封顶 `MAX_CONFIDENCE` 是 0.5，个人二元占一半权重，静态模型里「收到 → 邮件」104 次压不过去。
要修这条得从个人 n-gram 这一侧走（降低只见过两次的转移的权重，或让静态模型的强证据能翻案），不在本轮范围内。

## 个人二元加绝对折扣（2026-09-22）

接着上一节没修完的那条：个人二元原来是 `λ·c(v,w)/c(v) + (1−λ)·个人一元`，**没有折扣**，一次事件就能锁死首选。
用户自己点选的转移记 `EXPLICIT_TRANSITION_WEIGHT` 2 份，接缝上屏的第一个词也记 2 份，所以「一次误选」在文件里就是 2，
静态模型里 P(邮件|收到) ≈ 104/25354 ≈ 0.004 压不过去。这次给二元层也加绝对折扣，两层都是：

```
P₃ = max(c(u,v,w) − D₃, 0)/c(u,v) + 折出来的质量 · P₂
P₂ = λ·[max(c(v,w) − D₂, 0)/c(v) + 折出来的质量 · P_静态(w|v)] + (1−λ)·c(w)/N
```

三处取舍：

- **二元折出来的质量给静态模型，不给个人一元。**「这个前词后面用户没打过这个词」恰恰是该听静态模型的时候；
  个人一元只说这个词用户总共打过多少、与上文无关，撑不起回退。
- **`(1−λ)` 的个人一元那份留着**（λ 的含义不变）：它是「上文里没这个词」时的兜底，而且 D₂=0 时整个式子退回改前的样子，
  下面表里 D₂=0 / D₃=0.75 那格与改前逐条相同（8835 / 293），扫参的基线是真基线。
- **折出来的质量按实际折掉的算**（`1 − Σ max(c − D, 0)/总数`），不是惯用的 `D·类数/总数`：个人数据里计数比 D 小的条目占多数，
  按后者算 D=2、一行全是 1 时会算出 2，整行概率不再归一。改前 D₃=0.75 时两种算法相等，所以这一步不改旧数字。

### 怎么复现

```bash
cargo build --release -p glimmer-cli
# 扫参（默认已是 d2=2,d3=2，给 --tune 是为了比别的档）
target/release/glimmer-cli --config <配置副本> --replay <冻结日志> --misses 0 --tune d2=2,d3=2
# 留出学习
ls docs/**/*.md | sort > /tmp/all.txt; awk 'NR%5==0' /tmp/all.txt > /tmp/test.txt; awk 'NR%5!=0' /tmp/all.txt > /tmp/learn.txt
target/release/glimmer-cli --eval-text $(cat /tmp/test.txt) --eval-save /tmp/holdout.tsv --misses 0
target/release/glimmer-cli --learn-text $(cat /tmp/learn.txt) --eval-text /tmp/holdout.tsv --misses 0
```

逐例复核别对着输入法自己的数据目录跑：`--user-dict` 退出时会写回，先把 `~/Library/Application Support/Glimmer/` 复制一份出来。
