# AI 与软件开发词库验证（2026-09-17）

基于 main 的 `0adc4fc`，实现位于 `feat/development-lexicon`。数据不以凑满目标条数验收，按独立输入任务验证。

## 覆盖盘点

| 项目 | 数量 |
|---|---:|
| 源词条 / 不同词形 | 8,279 / 8,278 |
| 主词库同词同码，生成时排除 | 100 |
| 实际生成条目 | 8,179 |
| 与可选 IT 词库同词同码 | 2,788 |
| 与主英文表同码同词 | 205 |
| 与主英文表同码但显示词不同 | 353 |
| 正文中至少出现一次的源条目 | 1,188 |
| 正文中未出现、使用明确人工权重 | 7,091 |

英文显示词差异常包含大小写、符号差异，完整清单在 `ai-coverage.tsv`；领域表内同码不同词会直接阻止生成，主英文表仍按已有来源优先级处理。
具体词形和字段见 [词库源说明](../../assets/lexicon/ai/README.md)。正文共 6,131 段，包含原有教材 2,486 段以及新增 Vue/Rust 文档 3,645 段。
真实语料覆盖仍有限，尤其是工具名称、项目表达；不把未出现条目的人工权重包装成真实词频。

## 验证结果

- Rust 1.96.0 下全 workspace 测试：571 项通过。
- `cargo fmt --all --check`、`cargo clippy --all-targets --locked -- -D warnings` 通过；生成器最终定向测试通过。
- 独立开发场景 164 / 164 通过；中文与混合词前 5 命中 100%，必备英文和文件名均满足各自位置要求。
- 80 条普通中文输入，对比无附加词库和首版 AI 词库，首选均未变化。
- `cpp` 与 `csharp` 分别上屏 C++、C#；`gitfenzhi` 和 `apijiekou` 可整块上屏混合词；关闭词库撤销候选；同词多别名不重复占位。
- 首轮发现缺少「向后兼容」，已补齐；Spring Boot 被高词频的通用英文词挤到第六位，调整为个人选择优先、领域补全其次后通过。
- 真实正文提取规则、逐段来源序号、无重复段落和来源 ID 完整性已校验。
- shell 打包脚本语法及 diff 空白检查通过。

## 查询耗时

本机 Apple Silicon，debug 构建、关闭增量和调试符号；CLI 使用仓库主词库、英文表和样例释义，未接入生产 bigram/神经模型、云端预测或真实窗口。
每组 84 个完整输入，同进程预热后取样，交错运行三轮，共 252 个样本：

| 对比 | 完整查询中位数 | P95 |
|---|---:|---:|
| 首版 AI 词库 | 0.348 ms | 1.36 ms |
| 扩充后词库 | 0.358 ms | 1.42 ms |

另以 `--typing` 检查 开发、检索增强生成、解决合并冲突、Git分支 四组逐键输入。扩充后平均每键分别为 3.26、1.09、0.85、1.28 ms；第一组包含启动后的首次查询，最慢 11.83 ms，无词库基线最慢 12.36 ms。
这些是有限样本的单机证据，不是所有硬件或真实输入法的性能承诺。
